# Naming research: Linux ZoomIt clone

Checked 2026-09-30. 30 names: the 20 on the shortlist plus 10 of mine (focal, scrawl, inkling, kredka, blowup, zoodle, penlens, lumen, scribe, lupen).

The name becomes the binary, the `.desktop` app name, the app id (`io.github.<user>.<Name>`) and the repo name, so a collision anywhere in that chain matters.

## How each name was checked

- **Debian/Ubuntu**: `apt-cache search --names-only '^<name>'`, `apt-cache show`, and `command -v` on this box (Ubuntu 24.04). The local apt lists date from 2025-08-05, so I also queried the Launchpad archive API for exact source and binary names across every Ubuntu series (noble through resolute/26.04 and the current dev series), `sources.debian.org` for Debian, and the packages.ubuntu.com / packages.debian.org Contents search for a file named exactly `<name>` in Ubuntu noble, Ubuntu resolute and Debian unstable (catches `/usr/bin/<name>` shipped by a differently named package).
- **Flathub**: search API, filtered for an app id or name containing the candidate. The search is fuzzy, so unrelated hits are ignored.
- **Snap**: `api.snapcraft.io/v2/snaps/info/<name>`. A hit means the snap name is taken.
- **GitHub**: repo search `<name> in:name`, sorted by stars, top 30 scanned for exact name matches. Star counts are as of today.
- **Extras**: AUR, crates.io, PyPI, npm, Homebrew (name existence only).
- **Web**: one search for `<name> linux` per name, plus plain-name searches for the finalists.

Not checked: trademark registers (UKIPO, EUIPO, USPTO) and domain availability. Do a UKIPO/EUIPO search on the winner before printing anything with the name on it.

## What already exists in the space

Names to stay clear of: [Gromit-MPX](https://github.com/bk138/gromit-mpx), [Boomer](https://github.com/tsoding/boomer) (and its forks coomer, cboomer, several "zoomer"s), [Wayscriber](https://github.com/devmobasa/wayscriber) (calls itself a ZoomIt-like tool), [ZoomMe](https://github.com/zdo/zoomme), [KMag](https://apps.kde.org/kmag/), Magnus (snap), [ZoomitForMac](https://github.com/microsoft/ZoomitForMac). None of the 30 candidates matches any of these.

Verdict scale: **GOOD** = no meaningful collision, fits the brief. **OK** = usable, one real caveat. **WEAK** = collision or poor fit, avoid unless nothing else works. **REJECT** = clear collision.

## Top 3

**1. lupka.** It is the only candidate that is both clean and on-brief. I found no package, snap, Flatpak, AUR entry or registry name anywhere, and the two GitHub repos called Lupka have 0 stars each (one is a Windows magnifier last touched in 2022). "lupka linux" turns up nothing relevant, so the project would own that query once the repo exists. Five letters, easy to type, no Zoom trademark issue, and it ties to the author. The costs are real but small: English speakers will not know it means "little magnifying glass" (a one-line tagline fixes that), they may say LOOP-ka or LUP-ka (put a pronunciation line in the README), and plain "lupka" returns surnames, so lean on "lupka linux" and "lupka zoom" for search. It only hints at the zoom half, not the drawing half.

**2. penlens.** The best fallback if you want a name that explains itself to an English-speaking audience. Pen plus lens covers drawing and magnifying in one word, it is as collision-free as lupka (the GitHub name is even unclaimed, and the only namesake is a 2019 Android social app), and it is easy to say and spell. It loses to lupka on character: it reads like a generic compound, it is seven letters, and it has no link to the author. Pick this one if the README will be read mostly by people who have never met a Polish word.

**3. lupen.** A good pun (lupa plus pen, and close to the English "loupe") that covers both halves of the feature set, five letters, and free in every distro and registry. It is third because of momoraul/Lupen, an active, branded macOS app with a Homebrew cask that reaches the same developer audience, and because bare "lupen" search is German magnifier shops. Not a blocker, but a live namesake is a worse start than none. kredka and lunette are the next two if you want more options; kredka is entirely clean but only says "draw", lunette is clean but French and less typeable.

## Recommendation

**lupka.**

- Repo and binary: `lupka`
- App id: `io.github.<user>.Lupka` (for example `io.github.komsky.Lupka` if the repo lives under komsky), which also gives the `.desktop` file `io.github.<user>.Lupka.desktop` and the D-Bus name
- Suggested tagline: "Lupka: zoom, draw and snip on your Linux screen. (Polish for 'little magnifying glass', said LOOP-ka.)"

Before you commit to it, run a UKIPO/EUIPO trademark search and check the domain you want (lupka.app, lupka.dev). Neither was checked here.
